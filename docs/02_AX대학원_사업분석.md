## 2. 정부 AX대학원 사업 개요

| 항목 | 내용 |
|---|---|
| 주관 부처·전담기관 | 과학기술정보통신부 / 정보통신기획평가원(IITP) |
| 목적 | AI 기술 자체보다 산업 도메인에 AI를 접목하는 AX 융합 석·박사 인재 양성 [보도] |
| 공고·접수 | 2026.2.19 공고, 3.12~3.25 접수 [보도] |
| 규모 | 2026년 예산 150억 원, 대학원당 연 30억 원 내외, 최장 6년 [보도] |
| 컨소시엄 | 대학(주관) + 기업(공동연구개발기관), 융합분야 2개 이내 [보도] |
| 필수 요건 | 기업과 공동 AX연구협력센터 설치, 대학교원+기업 겸임교원 복수 지도교수제, 전주기 커리큘럼, 석·박사 패스트트랙, 석사 졸업요건을 AX연구프로젝트로 대체 가능, 대학원생 40명 이상 [보도] |
| 제한·가점 | 4대 과기원·교육부 AI거점대학 지원 불가, 비수도권 가점 3점 [보도] |
| 결과 | 2026.9.29 15개교 선정(비수도권 8곳), 공동연구개발기관 26개사, 연세대에서 AI중심대학·AX대학원 공동 출범식 [보도] |
| 중장기 | 2030년까지 22개교로 확대 계획 [보도] |

### 2026 선정 15개교 [검증, korea.kr 보도자료 첨부]
경국대(일지테크) · 금오공대(한화시스템, LIG D&A) · 서강대(포스코디엑스, 노타) · 성균관대(DN솔루션즈, 티라로보틱스) · 세종대(LIG D&A) · 순천대(대동, 이스트소프트) · 순천향대(동은정보기술, 씨어스) · 연세대(삼성전자, 원익아이피에스) · 인하대(삼성중공업 거제조선소, 케이지스틸) · **창원대(한화에어로스페이스)** · 포스텍(포스코홀딩스, 뉴로메카) · 한국에너지공대(한국전력공사, 티디엘) · 한림대(바디텍메드, 코어시큐리티) · 한양대(GS건설, 누리플렉스) · 한양대 ERICA(두산로보틱스, 마음에이아이)

방산 분야 선정교는 창원대 외에 금오공대(AX방산제조융합), 세종대(국방AX융합) 두 곳이다. 창원대는 **운용(무기체계 운용·정비·군수) + 제조(방산 생산 공정)** 두 축을 함께 다루고, TUG Campus·AROC 같은 실증 공간을 갖춘 점이 차별점이다.

- 매년 50명+ 선발, 석박사 250명+ 양성, 취업률 90%, 지역정주율 60%

- 등록금 전액 지원, 기준인건비 100% 이상(PDF)
- SCI·Top-tier 논문 300건, 특허 140건, 기술이전 30건, 전임교원 30명(PDF)
- AI 인프라 투자 3단계 12억 / 35억 / 55억(PDF)

## 5. 자료 간 차이와 미확인 사항

1. **산학장학생 선발 시기**: PDF "학부 2학년 2학기 선발", 공지 "학부 3학년 중 선발". 2학년 2학기에 선발해 3학년부터 장학생 신분이 되는 것으로 읽힌다. 홈페이지는 "학부 2학년 2학기 선발, 3학년부터 산학장학생"으로 둘 다 살려 적었다. 확정 문구는 사업단 확인 필요.
2. **국제협력 목표**: PDF "공동연구 15건+", 공지 "25건 이상". 홈페이지는 최신 공지 기준(25건 이상)을 쓰고, 협력기관 목록은 PDF를 따랐다. 공지에 언급된 폴란드 육군사관학교는 PDF 지도에 없어 별도 표기했다.
3. **사업명 표기**: 학교는 "AX혁신인재양성사업", 정부·언론은 "AX대학원". 홈페이지는 "과기정통부·IITP AX대학원(AX혁신인재양성사업)"으로 병기.
4. **모집요강 미공개**: 전형 일정, 지원 자격, 장학금 액수는 아직 공개되지 않았다. 홈페이지 입학 섹션은 "2027학년도 첫 모집 예정, 세부 요강은 공지 예정"으로 처리하고 문의처를 노출했다.
5. **정부 지원 총액**: "연 30억×6년"과 "정부 155억"이 다르다(첫해가 부분 연도일 가능성). 홈페이지는 학교 공식 수치(177억/155억)만 사용.
